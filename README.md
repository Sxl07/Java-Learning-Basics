## 🇪🇸 Cómo ejecutar los ejercicios

1. Clonar el repositorio:

```bash
git clone https://github.com/Sxl07/Java-Learning-Basics.git
```

2. Entrar al proyecto:

```bash
cd Java-Learning-Basics
```

3. Compilar un archivo Java:

```bash
javac NombreDelArchivo.java
```

4. Ejecutar el programa compilado:

```bash
java NombreDelArchivo
```

> Reemplaza `NombreDelArchivo` por el nombre real de la clase que contiene el método `main`.

## 🇬🇧 How to Run the Exercises

1. Clone the repository:

```bash
git clone https://github.com/Sxl07/Java-Learning-Basics.git
```

2. Enter the project folder:

```bash

```

3. Compile a Java file:


4. Run the compiled program:

